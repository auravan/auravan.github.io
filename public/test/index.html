满意度回归分析：有效样本与原数据、变量公式说明

一、有效样本原数据

  • 文件：回归有效样本_原数据.xlsx
  • 内容：参与回归的 315 条 有效样本的完整原数据。
    • 包含问卷中全部原始列（如序号、人口学、各题原始作答等）。
    • 另增加以下回归用变量（由原始题项计算得到）：
      • 满意度_回归用：因变量的数值（用于回归的满意度）
      • 情感价值EV_回归用、社会价值SV_回归用、名誉价值RV_回归用、功能价值FV_回归用、服务价值PSQ_回归用：五个自变量的数值（用于回归的维度得分）。
  • 有效样本定义：同时满足
    （1）满意度有效（SAT1、SAT2、SAT3 三道题均能提取出 1–5 分）；
    （2）五个价值维度（EV、SV、RV、FV、PSQ）各自题项均能提取出 1–5 分，且维度均值无缺失。

运行 regression_satisfaction.py 后会自动生成该 Excel 文件。

二、原始题项与数值提取规则

问卷中题项为文本选项（如「1非常不同意」「4同意」）。回归前统一按下列规则转为 1–5 数值：

  • 提取规则：取该题第一个字符；若为数字 1–5，则记为该题的数值，否则记为缺失。
  • 缺失：若该题为空、(跳过) 或无法解析出 1–5，则该题数值为缺失，不参与该题所在维度均值的计算；若某样本在因变量或任一二阶维度上存在缺失，则不进入有效样本（即不参与回归）。

三、回归时变量的计算公式

1. 因变量：满意度

  • 含义：游客满意度，由问卷中 23 题下三道满意度题项构成。
  • 对应题项（列名）：
    • SAT1：23、满意度—SAT1. 总体而言，我对豫章书院的参观体验感到满意
    • SAT2：23、SAT2. 豫章书院的实际体验符合甚至超出了我的预期
    • SAT3：23、SAT3.我认为到豫章书院游玩是个合适的选择
  • 公式：
    • 对每题按「二、原始题项与数值提取规则」得到数值 ( \text{SAT1}, \text{SAT2}, \text{SAT3} \in [1,5] )（缺失则不参与）。
    • 因变量为三道题数值的算术平均值： [ \text{满意度} = \frac{\text{SAT1} + \text{SAT2} + \text{SAT3}}{3}. ]
    • 仅当 SAT1、SAT2、SAT3 均有有效数值时，该样本才有「满意度」，并可能进入有效样本。

2. 自变量：情感价值（EV）

  • 对应题项：
    • EV1：18、情感价值—EV1. 豫章书院的氛围让我感到愉悦
    • EV2：18、EV2. 在豫章书院参观或体验让我感到身心放松
    • EV3：18、EV3. 我感觉到豫章书院游玩心情愉悦
  • 公式：每题按上述规则得到 1–5 数值后， [ \text{情感价值EV} = \frac{\text{EV1} + \text{EV2} + \text{EV3}}{3}. ]

3. 自变量：社会价值（SV）

  • 对应题项：
    • SV1：19、社会价值—SV1. 参观豫章书院是一种有文化品位的体现
    • SV2：19、SV2. 我会因为推荐豫章书院而获得他人的好感
    • SV3：19、SV3. 豫章书院的重新发展将得到社会的支持
  • 公式： [ \text{社会价值SV} = \frac{\text{SV1} + \text{SV2} + \text{SV3}}{3}. ]

4. 自变量：名誉价值（RV）

  • 对应题项：
    • RV1：20、名誉价值—RV1. 豫章书院在本地有良好的声誉
    • RV2：20、RV2. 豫章书院经常被他人高度评价
    • RV3：20、RV3. 豫章书院被他人尊重
  • 公式： [ \text{名誉价值RV} = \frac{\text{RV1} + \text{RV2} + \text{RV3}}{3}. ]

5. 自变量：功能价值（FV）

  • 对应题项：
    • FV1：21、功能价值—FV1.我感觉到豫章书院游玩受益匪浅
    • FV2：21、FV2. 我感觉书院项目的安排符合实际需求
    • FV3：21、FV3. 参观书院增强了我的文化认同感
    • FV4：21、FV4. 书院提供了独特的社交体验
  • 公式： [ \text{功能价值FV} = \frac{\text{FV1} + \text{FV2} + \text{FV3} + \text{FV4}}{4}. ]

6. 自变量：服务价值（PSQ）

  • 对应题项：
    • PSQ1：22、服务价值—PSQ1. 书院环境卫生整洁
    • PSQ2：22、PSQ2. 服务人员态度友好
    • PSQ3：22、PSQ3. 导览标识清晰易懂
    • PSQ4：22、PSQ4. 书院设施便利（休息区、洗手间等）
  • 公式： [ \text{服务价值PSQ} = \frac{\text{PSQ1} + \text{PSQ2} + \text{PSQ3} + \text{PSQ4}}{4}. ]

四、实际回归时的模型公式

回归采用多元线性回归（OLS），模型为：

[ \text{满意度} = \beta_0 + \beta_1 \cdot \text{情感价值EV} + \beta_2 \cdot \text{社会价值SV} + \beta_3 \cdot \text{名誉价值RV} + \beta_4 \cdot \text{功能价值FV} + \beta_5 \cdot \text{服务价值PSQ} + \varepsilon, ]

其中 ( \varepsilon ) 为误差项。本次估计结果（未标准化）为：

参数 估计值 含义
( \beta_0 ) (const) 1.6179 截距
( \beta_1 ) 0.1239 情感价值EV 每增加 1 分，满意度平均增加约 0.124 分
( \beta_2 ) 0.2105 社会价值SV 每增加 1 分，满意度平均增加约 0.211 分
( \beta_3 ) 0.0471 名誉价值RV 每增加 1 分，满意度平均增加约 0.047 分
( \beta_4 ) 0.0234 功能价值FV 每增加 1 分，满意度平均增加约 0.023 分
( \beta_5 ) 0.1579 服务价值PSQ 每增加 1 分，满意度平均增加约 0.158 分

即实际回归时使用的公式为：

[ \boxed{ \text{满意度} = 1.618 + 0.124 \cdot \text{情感价值EV} + 0.211 \cdot \text{社会价值SV} + 0.047 \cdot \text{名誉价值RV} + 0.023 \cdot \text{功能价值FV} + 0.158 \cdot \text{服务价值PSQ}. } ]

上述公式中，满意度、情感价值EV、社会价值SV、名誉价值RV、功能价值FV、服务价值PSQ 均由第三部分给出的题项与计算公式得到；回归使用的样本即「有效样本原数据」中的 315 条。
